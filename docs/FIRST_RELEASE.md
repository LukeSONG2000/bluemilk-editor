## 0.2.2 修正

- 悬浮窗采用原版九宫格，修正非客户区白边与底层不透明合成。黑白底实测中心 Alpha 为 237/255，客户区等于窗口尺寸。
- 连接修复不再缓存登录前的旧 GameConstants：跟随预检协程实际购买控制器；状态报告真实值，停用还原所有持有配置并释放 GC 引用。
- 原版青铜免费领取一次及两种修复模式的盟友点购买均成功（各 250 点）。诊断期间一次多探针集中卸载引发 frida-agent.dll 崩溃，已记录、重启原客户端并改为单会话验证；不将这次诊断异常掩盖成正常退出。

## 0.2.3 悬浮窗

- 主页/Mod 页入口为 Segoe Fluent Icons MiniExpand（E93A）；展开窗口用 BackToWindow（E73F）收起，没有叉号。
- 收起后仅显示双杯应用图标：单击展开、拖动移动、右键菜单关闭。重复点击入口恢复同一窗口，停用 Mod 或退出 Editor 会一并清理。
- 页面不可见且窗口收起时暂停属性请求；恢复后立即刷新。窗口按显示器 DPI 适配并限制在工作区内。
- 按最新验收意见采用 8 DIP 小圆角和细边框，移除 Pro 的原版斜角九宫格；保留原版面板底色 (25,41,64) 与 Alpha 237/255。
- Pro 修正原版字体的显示族名：资源/PostScript 名 MYingHei_18030_C-Medium 与 DirectWrite 族名 MYingHei_18030_C 不同。此前仅检查 UIA FontName 不能证明实际字形来源；系统注册还会留下 XAML 首次加载的旧字体集合。本次悬浮窗通过 Win2D 从校验后的本地文件绘制真实字形（无需字体安装或重启），保留 XAML 布局和可访问文字，普通页面仍用原生文字控件。未改变的文字不重复绘制，不使用连续渲染循环。字体不随安装包分发。
