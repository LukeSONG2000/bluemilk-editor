# Editor + Pro 首版验收

按项验收后发布，保持首版范围小，不使用 /goal。

- [x] Editor 为自包含 EXE 安装包；默认管理员 Program Files，可选当前用户与自定义目录，升级保留配置。
- [x] 通用 Mod 包管理、拖入/双击 `.bluemilk`、离线启停意图、自动连接与恢复。安装包不附带 Pro/Ultra。
- [x] Pro 以独立包提供原版血盾绝对值、敌方技能 CD、有限回合状态、初始/当前属性。
- [x] 主页和 Mod 页使用同一属性表格，当前值后显示有色增减，长按详情角色优先于目标选择器。
- [x] 属性置顶悬浮窗；背景颜色/透明度与字体来自本地原版资源，不分发游戏字体。
- [x] Pro 增加 EA 连接修复：原版 2 秒 / 延长至 15 秒 / 跳过官网预检，保留认证、真实交易与奖励校验。
- [x] Pro/Ultra 采用 Editor 双杯图标；包文件保留单杯图标。
- [ ] 最新安装包到真实用户环境的最终验收；安装 Editor → 导入 Pro → 打开游戏 → 启用 → 小队竞技场实战。
- [ ] 验收后推送 Editor/Pro 并发布 GitHub Release。

已确认 PC 免费宝箱的失败发生在 `PurchaseController.PingURLCheck` 官网预检：2.0012 秒时请求未完成便判失败，尚未进入真实购买。延长模式下真实领取成功；该次网站请求在 0.94 秒完成，因此不能据此断言已证明所有慢请求均解决。跳过模式另经原版 Unity 协程验证，回调一次且不伪造购买。卸载/停用会恢复本模块拥有的预检改动。

DNS 实测处于 Mihomo fake-IP 环境，指定多个解析器仍得到相同 fake IP，不能据此推荐“最快 DNS”。首版不修改系统 DNS 或代理。EA 平台认证失败、真实服务端故障不属于跳过官网预检能修复的范围。

后续迭代：跨游戏版本的动态适配、属性变化因素归因、Ultra、远程连接。当前属性增减是净变化；并非已经准确解释所有变化来源。当前适配仍校验已支持游戏版本，不宣称更新后必然通用。

## 0.2.2 修正

- 悬浮窗采用原版九宫格，修正非客户区白边与底层不透明合成。黑白底实测中心 Alpha 为 237/255，客户区等于窗口尺寸。
- 连接修复不再缓存登录前的旧 GameConstants：跟随预检协程实际购买控制器；状态报告真实值，停用还原所有持有配置并释放 GC 引用。
- 原版青铜免费领取一次及两种修复模式的盟友点购买均成功（各 250 点）。诊断期间一次多探针集中卸载引发 frida-agent.dll 崩溃，已记录、重启原客户端并改为单会话验证；不将这次诊断异常掩盖成正常退出。
